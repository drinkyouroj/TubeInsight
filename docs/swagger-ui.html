TubeInsight API

Comprehensive REST API for YouTube Video Sentiment Analysis

🚀 Getting Started

  • Base URL: https://your-domain.com/api
  • Authentication: Supabase JWT Bearer Token
  • Content-Type: application/json
  • API Version: v1.0.0

🔐 Authentication

Include your Supabase JWT token in the Authorization header:

Authorization: Bearer <your_jwt_token>

Tokens are obtained through the frontend authentication flow.

📊 Core Features

  • Analyze YouTube video sentiment
  • Retrieve analysis history
  • Get detailed analysis results
  • Admin user management
  • System health monitoring

⚡ Rate Limits

  • Analysis: 10 req/min per user
  • History: 60 req/min per user
  • Admin: 100 req/min per admin
